# Abartılı Çay Molası Hesaplayıcısı

## Bu Nedir?

Bu proje, insanlığın en büyük sorunlarından birini çözmeyi amaçlamaktadır: **Çay molası süresi ne kadar olmalıdır?**

Bilimsel araştırmalar, rastgele sayı üretimi ve abartılı yorumlar ile desteklenen bu hesaplayıcı, ofis hayatınızı kökten değiştirecektir. Ya da hiçbir şey değiştirmeyecektir. Ama en azından çok ciddi görünmektedir.

## Özellikler

- ✔️ Stres seviyenize göre dinamik süre hesaplama
- ✔️ Çay sıcaklığı ve ofis sıcaklığı arasındaki farkı dikkate alma
- ✔️ Abartılı ve tamamen gereksiz bilimsel yorumlar
- ✔️ 2 saniye bekleyerek "hesaplama yapıyorum" hissi yaratma
- ✔️ Hiçbir şey yapmayan gizli değişkenler (sadece orada dururlar)

## Kurulum

Python 3 gereklidir. Başka hiçbir şey gerekmez. Çay da gerekmez ama tavsiye edilir.

```bash
python cay_molasi.py
```

## Kullanım

Stres seviyenizi girin (1-10 arası). Program size mola sürenizi ve bir yorum verecektir. Yorumu ciddiye alıp almamak tamamen size kalmıştır.

## Bilimsel Temel

Formül şöyledir:

```
Süre = Stres * Rastgele(0.5-3.0) + |Çay Sıcaklığı - Ofis Sıcaklığı| / 10
```

Bu formül, en az 0 bilimsel makalede yayınlanmıştır.
